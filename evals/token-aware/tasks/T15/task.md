Write a script named sla_breaches.py that reads data/tickets.csv and writes out/sla_breaches.json, then run it so the output file exists. Business time runs Monday to Friday, 09:00 to 17:00 UTC, with no holidays, and it does not run at weekends or outside those hours. The SLA is 4 business hours for priority P1, 8 for P2 and 16 for P3. Measure from opened_at to closed_at in whole business minutes, where a minute counts when its start falls on a weekday between 09:00 and 16:59 UTC. A ticket is breached when its business time is greater than its SLA. Tickets with a blank closed_at are still open, are not breached, and are counted separately. The JSON object has three keys: breached, a sorted list of ticket ids; closed_tickets, the number of tickets with a closed_at; and open_tickets, the number of tickets without one.
