Write a script named latency_report.py that reads data/requests.log and writes out/latency_report.txt, then run it so the output file exists. Each line holds space-separated key=value pairs, and the pairs may come in any order. A line is valid only when it has a route and an ms value, and ms is written with digits only. Blank lines are ignored and not counted. Invalid lines are skipped and counted. Use every valid request, whatever its status. For each route, write one line with the route, the count, p50, p95 and max, where each percentile uses the nearest-rank method: the p-th percentile is the value at 1-based rank ceil(p times n over 100) in the sorted list of ms values for that route. Sort the route lines by route name, and finish with a line that reads skipped=K. Write each route line exactly as `route=<route> count=<n> p50=<v> p95=<v> max=<v>`, five space-separated key=value pairs in that order, with no other text.
