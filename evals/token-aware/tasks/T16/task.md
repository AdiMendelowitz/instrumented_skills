Flatten data/devices.json, a JSON array of device records, into one CSV row per device. Write the code in flatten_devices.py and save the result to out/devices_flat.csv, then run the script so the output exists. Nested object keys are joined with dots, so the value at site.geo.lat becomes the column site.geo.lat. A list of plain values is written as its items joined by semicolons. An empty list becomes an empty cell, null becomes an empty cell, and a key that a record does not have becomes an empty cell. Booleans are written as true or false. An empty object adds no columns. The columns are the sorted union of all flattened keys over every record, sorted as plain text. Rows keep the order of the input array. Write other numbers exactly as Python writes them when converted to text.
