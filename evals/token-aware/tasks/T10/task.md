The publishing service builds URL slugs in text/slugs.py. The function make_slug gets three cases wrong: accented letters vanish instead of becoming their base letters, long titles are cut in the middle of a word, and a cut can leave a trailing hyphen. Fix make_slug so that accents are removed through Unicode decomposition, and so that a slug longer than max_len is cut back to the last whole word that fits. If the first word alone is longer than max_len, cut it at max_len. Then add unique_slug(slug, taken) to the same file. It returns slug when slug is not in taken, otherwise slug-2, slug-3 and so on, returning the first free one. It must not change taken. Keep MAX_LEN and the signature of make_slug. Use only the standard library and edit text/slugs.py only.
