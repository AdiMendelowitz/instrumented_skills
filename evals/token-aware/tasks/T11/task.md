Build monthly revenue figures from the order export in data/orders.csv. Write a script named build_monthly.py in the working directory that reads the export and writes out/monthly_revenue.csv, then run it so the output file exists. Count only orders whose status is paid, ignoring case and surrounding spaces. An order that appears more than once in the export counts once. Orders with a blank amount_eur are left out. Months are calendar months in UTC, taken from placed_at, which carries a UTC offset. Region names are case-insensitive, so write them in upper case. The output has the columns month, region, orders and revenue_eur, with one row for each month and region that has at least one counted order, sorted by month and then by region. Write revenue with exactly two decimal places.
